キーワード: ハングル,韓国語,日本語,キーボード,タイピング,フリック,韓国,練習,学習

説明:
ハングルの入力、日本語への候補変換、韓国語・日本語のタイピング練習をひとつのアプリで。

ハングルフリック、チョンジイン、QWERTYから配列を選べます。ハングルで入力した日本語の発音から日本語候補を表示します。日本語のかなフリックとは異なる、ハングルのための配列です。

韓国語の意味・ハングルの読み・日本語を並べて見る練習に加え、RainとCafeのタイピングゲームを用意しています。BGMと効果音は個別に切り替えられます。

キーボードの追加方法:
設定 → 一般 → キーボード → キーボード → 新しいキーボードを追加で本アプリを追加します。入力画面の地球儀キーで切り替えてください。キーボード内の設定から配列を変更できます。フルアクセスを有効にしなくても、基本入力と端末内の日本語変換を利用できます。

入力内容と練習の解答を独自のサーバーへ送信しません。広告はアプリ本体とゲームでのみ提供し、キーボード拡張には表示しません。対応範囲とデータの取り扱いはアプリ内の案内をご確認ください。
