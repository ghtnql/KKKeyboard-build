## 6. 배포 및 보안 주의

- Google Drive 프로젝트 폴더에서 App Store Connect 계열로 보이는 `.p8` 인증키 파일을 발견했으며, 키 내용은 읽거나 복사하지 않고 2026-09-23 영구 삭제했다. 삭제 후 프로젝트 폴더의 `.p8` 파일이 0개임을 재확인했다.
- Drive 파일 삭제는 Apple 측 키를 무효화하지 않는다. 공유 중 노출 가능성이 있었다면 App Store Connect에서 해당 키를 폐기·재발급하고 GitHub Environment Secrets 등 제한된 비밀 저장소에서만 사용해야 한다.
- 성공한 CI/TestFlight/Google Play 업로드가 곧 스토어 심사 완료나 공개 출시 완료를 뜻하지 않는다.

## 7. 상태 해석 규칙

- `구현됨`: 코드와 최소 자동 테스트가 존재함
- `검증됨`: 현재 저장소 또는 CI에서 실제 테스트/빌드 성공을 확인함
- `배포됨`: 해당 테스트 배포 채널로 업로드 성공을 확인함
- `출시 완료`: 스토어 심사와 공개 배포까지 확인한 경우에만 사용
- Drive의 `review_required` 콘텐츠는 “준비됨”이 아니라 “초안 생성 완료, 검수 대기”로 해석한다.
