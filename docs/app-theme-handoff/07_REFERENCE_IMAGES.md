# 시각 참고 이미지 사용 규칙

기존 Drive 폴더 `테마_디자인_개발전달_초안`의 PNG는 색감/질감 참고용이다.

참고 우선순위:
1. `01_seoul_day_home_handoff.png` — 서울 낮 색감/밝기/카드 톤
2. `04_seoul_night_home_handoff.png` — 서울 밤 색감/표면/포인트 톤
3. `07_dark_home_handoff.png` — 일반 다크 surface 계층/대비
4. theme settings/keyboard handoff 이미지 — 선택 상태와 키보드 배색 참고

중요:
- 이미지에 그려진 네비게이션/기능/채팅 구조는 구현하지 않는다.
- 실제 앱 `KKKeyboardApp.kt`의 화면 내용에 위 시각 언어만 입힌다.
- 이미지 안 텍스트/치수보다 `02_APP_THEME_TOKENS.json`과 현재 코드가 우선이다.
