# 日本向け検索名（2026-10-10 調査）

アプリ内表示は韓国語・英語 UI で `ㅋㅋ키보드`、日本語 UI で標準表記 `ㅋㅋキーボード`。`ㅋㅋキ-ボ-ド` は長音符を ASCII ハイフンに置き換えた表記なので、表示名は既存の自然な表記を維持する。

App Store の日本語 keywords はカンマ区切りで計100文字以内。名称を読めない人向けの実用的な候補：`ククキーボード,ケーケーキーボード,ダブルケーキーボード,kkkeyboard,ハングル,韓国語入力,日本語変換,かな,フリック,タイピング`（既存キーワードと照合して重複を除く）。アプリ名と同一文字列の重複は避ける。追加でローマ字検索の `kkkeyboard` も検索メタデータとして保持できる。ユーザー画面には露出させない。

Google Play のタグは既定の候補から最大5個を選ぶので任意のブランド別名を自由入力する機能ではない。日本語説明の最初の紹介文に `ㅋㅋキーボード（ククキーボード／ケーケーキーボード）は、ハングルの発音入力から日本語へ変換できるキーボードです。` を自然に記載する。キーワードの羅列や無関係なタグは避ける。

検索順位・即時検索ヒットは保証されない。今回は調査と登録案の用意でありストアへの書き込み、審査取り下げ、再提出は行っていない。
