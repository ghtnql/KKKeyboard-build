# App Store 한국어 설명 — 광고 전용 출시

App Store Connect 반영 여부는 진척 기록의 실제 API 결과로 확인한다.

ㅋㅋ키보드는 한글 입력과 일본어 후보 변환을 제공하고, 한국어·일본어를 연습할 수 있는 키보드 앱입니다.

• 쿼티, 천지인, 한글 플릭 배열
• 한글로 입력한 일본어 발음의 후보 변환
• 한국어 의미·한글 발음·일본어를 함께 보는 타자·단문·변환 연습
• Rain과 Cafe 타자 게임, 기기 내 학습 기록
• 테마, 높이, 숫자열, 입력 간격, 햅틱 설정
• 게임 배경음악과 효과음의 개별 설정

iPhone 설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가에서 ㅋㅋ키보드를 추가하고, 입력 화면의 지구본 키로 선택해 주세요. 전체 접근 허용 없이 기본 입력과 기기 내 일본어 변환을 사용할 수 있습니다.

키보드 입력 내용과 학습 답안을 자체 서버로 전송하지 않습니다. 광고는 본체 앱과 게임에서만 제공하며 키보드 입력기에는 표시하지 않습니다. 광고 서비스의 데이터 처리는 개인정보처리방침을 확인해 주세요. 로그인 없이 사용할 수 있습니다.
