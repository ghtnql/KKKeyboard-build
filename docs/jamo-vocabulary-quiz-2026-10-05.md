# 일본어 발음 안내와 게임 단어 퀴즈

APK 288의 자모 이름/글자 선택 문제는 게임에서 단어를 읽는 학습으로 이어지기 어려웠다. 사용자 지시에 따라 기본 24자 카드에 일본어 가나·로마자 발음 안내를 붙이고, Rain/Cafe의 실제 단어로 확인 문제와 별도 단어 퀴즈를 만든다.

## 학습과 문제

- 자모 카드는 글자, 보조 한국어 이름, 일본어 소리 안내, 실제 게임 예시를 표시한다. 예: ㄱ의 カ・ガ行(k/g), 牛乳 → 규우뉴우 (우유). 우유의 한글 표기는 기존 게임에 있는 규우뉴우를 보존하며 게임에 없는 가나 읽기나 새 번역을 만들지 않는다.
- 가나는 발음의 근사 안내다. ㅓ/ㅗ, ㅕ/ㅛ, ㅡ/ㅜ를 구별하고 일본어와 완전히 같은 소리로 설명하지 않는다. 소리 구분은 [일본어 한국어 학습 과정의 발음 자료](https://www.penguin99.com/05_pronunciation/kisohen/kisohen_top.html)와 대조했다.
- 확인 문제를 열면 학습 카드 전체를 숨긴다. 일본어 원문과 과제 문구만 제시하고 실제 게임의 한글 단어 네 개 중 고른다. 글자·이름·가나 설명·카드 예시·뜻이 정답 힌트로 남지 않는다. 오답에는 정답/뜻을 공개하지 않고 맞힌 뒤에만 해당 단어의 원문·발음·뜻을 보여준다.
- 카드에서 본 두 예시는 다른 후보가 있으면 문제에서 제외한다. 다시 풀기와 다음 문제도 바로 직전 문항을 피한다. 다른 실제 단어의 표기 거리와 분류를 사용해 오답을 고르며 정답의 인정 표기가 오답으로 섞이지 않도록 제외한다.
- 일본어 발음에 해당 자모 예시가 없는 ㅓ/ㅕ 등은 실제 한국어 게임 단어를 사용한다. 카드와 문제에서 한국어 단어 과제로 표시해 일본어 발음 표기와 혼동하지 않는다. 기본 24개 자모 모두 실제 데이터에서 예시/문제를 확인한다.

## 공통 동작과 데이터

`JamoWordCatalog`는 기존 `AppPlatform.learningItems`와 `PracticeTranslationCatalog`를 사용한다. gameTypes의 rain/cafe 정확한 값, 해당 언어 모드, 실제 정답·원문·뜻이 있는 항목만 포함한다. 중복을 합치되 단어의 원래 sourceId를 보존한다. 게임 JSON과 검수 상태는 변경하지 않는다. 합성 단어·가짜 보기·별도 하드코딩된 예시 목록은 없다. 문항이 충분하지 않으면 정답 중복 문제를 만들지 않고 없음 상태를 표시한다.

입문 단어 퀴즈는 한글 정답 길이 8자 이하만 사용한다. 실제 렌더에서 게임의 긴 시 구절이 문제로 선택되는 것을 발견해 짧은 실제 단어 중심으로 제한했다. 원래 게임 콘텐츠와 정답은 그대로 두고 이 기초 과정에서만 필터링한다.

Android와 iOS는 같은 공통 화면/카탈로그/선택·공개 규칙을 호출한다. 이번 변경은 네이티브 인터페이스와 생성자, 진도 저장 키를 바꾸지 않는다. 자모 확인 문제 정답만 기존 해당 자모 진도에 저장한다. 별도 단어 퀴즈는 관련 없는 자모의 완료 상태를 바꾸지 않는다. 탭은 좁은 화면에서 줄바꿈되고 양쪽 플랫폼의 목록·뒤로·닫기 경로를 유지한다.

총괄이 공통 모델 검사, Android 실제 Launcher/네이티브 및 게임 데이터 검사, 한국어·일본어 렌더링과 실제 APK 설치/동작을 검증한다. Linux에서 새 iOS Swift/Xcode/iPhone 검사는 하지 않으며 공통 구현을 iOS 실기기 동등성 검증 완료로 표시하지 않는다. APK 사용자 테스트 이후 같은 소스의 AAB/iOS를 진행한다.

Muse Spark는 모델과 UI를 격리 공간에서 편집했다. 총괄은 첫 UI의 퀴즈 중 카드 노출 및 첫 모델의 한국어 답에 일본어 발음을 사용하는 오류를 발견해 각각 좁힌 후속 편집을 맡겼다. 부분 완료된 모델 후속 결과를 보존하고 남은 답 선택/필터/문자열 보존만 추가 작업으로 마쳤다. 실제 변경을 통합하고 검사·Drive 기록·빌드·전달은 총괄이 수행한다. GPT 하위 작업자는 사용하지 않는다.

## 검증 결과

공통 검사 9개, Android 학습/일본어 화면 검사 11개, 기존 게임 입력/오디오 회귀 검사 22개가 통과했다(서로 다른 검사 총 42개). 길이 제한을 추가한 최종 코드로 공통 9개와 학습/일본어 화면 11개를 다시 실행했다. 기본 24개 자모의 실제 문항 생성, 오답 비공개, 정답 공개/저장, 과정 재진입, 번역 과제와 발음 과제 구별을 확인했다. 실제 렌더에서 카드와 퀴즈 화면을 대조했다. APK의 설치 및 Drive 다운로드 검증 결과는 기존 Drive 진행 문서에 별도로 기록한다.

Muse의 실제 호출은 모델 4회·UI 2회이며, 마지막 모델 호출은 렌더에서 확인한 긴 구절을 이 기초 과정에서 제외하는 한 파일 편집이다. 호출 결과에 사용량이 제공되지 않아 토큰 절감 수치를 주장하지 않는다.
